# 船只形制修订：执行记录

日期：2026-11-10。状态：完成。本记录保存已核对的资料、来源保护和实际验收结果；形制与工程结论仍限于本项目模型。

## 已核对的资料与采用边界

- [泉州市人民政府资料](https://www.quanzhou.gov.cn/zfb/xxgk/zfxxgkzl/qzdt/qzyw/202402/t20240204_3002556.htm) 描述泉州湾后渚港宋船残体为尖头方尾、尖底、三重舷侧板、二重船底板和十三隔舱。它只作为福建尖底海船的类型比较，不是郑和船直接证据。
- [上海交通大学董浩云航运博物馆藏品条目](https://maritimemuseum.sjtu.edu.cn/info/1161/5821.htm) 记1957年南京三汊河附近中保村、宝船厂六作塘遗址出土舵杆全长11.07米；其归属写作“据学者考证”。本项目只把11.07米作为比较值，不用它反推两套宝船尺度、吃水、舵叶尺寸或出土舵杆的确切原船归属。

方艉、尖底、多重隔舱是福船类型考古实物比较；平板船首、帆形、桅位、舵叶形状与尺寸是建模假设或类型比较。本轮新增引用均已亲自打开核对，没有新增“出处待核”条目。

## 验收结论与边界

五类船、两套宝船尺度、完整与剖视均通过：网页模型低于三万三角面；艉封板顶部宽度及后倾、船首封板顶部宽度和舯部宽度满足新增断言；最高四根桅居中且所有桅偏置受限；舵叶低于船底且 `rudderStock` 为有限正值；帆面上的桅位置比例合格；隔舱、甲板、舱口和货物不穿出船壳。既有检查没有被删除、跳过或放宽。
