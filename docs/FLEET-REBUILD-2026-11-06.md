# 五类船独立母版重建

开始日期：2026-11-06；本文于2026-11-09更新。范围经用户确认：五类船均采用独立 Blender 母版流程，保留宝船已完成的精修，重建其余四类的船体、船楼、桅帆和用途空间。此前宝船成果先提交为 `410ad14`。

## 依据与假设

再次核对[中国机械工程数字博物馆《郑和航船》](https://museum.cmes.org/machinery/search/detail/c5eb6f090e9a48cbb5b68221cece11c0)及[《三宝太监西洋记》第十五回](https://zh.wikisource.org/zh-hant/三寶太監西洋記/015)。馆方采用五类船及五至九桅的传统展示体系；小说也列出相应船名、桅数和尺寸。这不能构成五类实船布局已经测绘、或每类固定桅数的直接证据。

本轮没有把小说丈尺或馆方大船换算尺寸套到既有小尺度模型。保留宝船61.2×13.8米研究解释，以及马船49×11.5米、粮船43×11.8米、坐船37×8.8米、战船30×6.8米的既有用途比例假设。宝船另一套《明史》尺度折算仍使用参数模型。此前的福船、后世船模和分片帆资料仅作构造比较，沿用[形制说明中的边界](BAOCHUAN-FORMS-2026-11-05.md)。

## 建模决定

四类新模型分别生成原生可编辑构件，没有将宝船整体缩放成其他船型。船壳、端板与隔舱有实际厚度；甲板开孔、舱口围板、架高舱底、肋骨、梁柱、桅座、艉舵和锚具均独立保留。

| 船型 | 船楼与甲板 | 舱内用途示意 |
| --- | --- | --- |
| 马船 | 两层艉楼，前部露台，上层退让 | 空马栏、侧栏、饲槽；未模拟马匹装卸或核定载马数 |
| 粮船 | 一层低艉楼，保留货舱上方操作甲板 | 垫板与分组粮袋；未核定载重量、防潮与粮储管理 |
| 坐船 | 两层艉楼，按人体尺度设置门窗、楼高 | 单层卧铺、床脚、储物箱；未核定床位与人员编制 |
| 战船 | 一层紧凑艉楼，侧部盾板，开敞甲板 | 器械柜和长杆器械；不移植后世舷侧炮列 |

四类帆装按主、首、艉、辅帆分为5、6、8幅；较高主桅回到中线并避开舱口，较窄船体的偏置辅桅外移，为通路留出位置。每类均保留一面前部辅帆的展开、半收、收拢姿态，包括对应帆骨、升帆索和控帆索。三种状态是离散位置示范，未求解绳长守恒、受力或风载。

检查发现坐船、战船的桅座占用主甲板通路，战船前部的舱口盖占用窄通道。已调整辅桅位置；战船盖板转为横向，分片堆放在开口后方。其余船盖板靠舷堆放。绞盘操作位避开舱口围板。局部通路按0.65米宽、1.70米高的模型目标检查，不引申为安全标准或整船通行认证。

生成后的检查图还发现四类新船的肋骨中心初始落在外壳线上，局部会穿出船板外表面。修复后，肋骨改为位于船板内侧24厘米的模型位置；这只处理了本项目船壳—肋骨的可见穿插关系，并不表示已复原原船的肋骨断面、连接工艺、间距或受力。马船和粮船从已有母版制作独立修订副本、检查后采用；坐船和战船则从已修正的底稿初始化。宝船母版未参与这次修复。

坐船的实际预览随后显示，偏置桅的桅座仍有部分穿入船壳。桅座的基础高度改为按整个桅座占地范围内的船壳高度计算，避免只取桅心位置而忽略斜坡；偏置桅座缩为1.20×0.60米的模型假设，并增加横向承座梁。坐船和战船的前部偏置辅桅从0.34倍船宽内移到0.29倍船宽；后部桅位保持原有通路避让。该改造同样先在各自独立研究副本中完成，原母版均保留备份。

新研究副本已用实际完整/剖视顶点检查桅座、承座梁与船壳的关系，并重跑原有通路检查；这些是本项目模型的局部构造检查，不构成桅杆受力、甲板承载或整船结构认证。

## 制作流程

五类船各有 `generated/<ship>-baseline.blend` 和独立 `<ship>-master.blend`。重建底稿只更新底稿，初始化拒绝覆盖已有母版，导出只读已保存母版。网页产物分完整与剖视，每份目标为不超过三万三角面；导出阶段会生成1024×1024颜色和法线图并嵌入GLB，完整与剖视的货物和桅位必须保持一致。

网页按所选船型载入、解码相应完整/剖视模型，缓存互相独立；一个船型失败时应回退参数模型，不阻塞其他船型。自包含离线版将内嵌十份GLB，但仍只解码用户查看的船型。舰队总览保持轻量实例模型，不把高细节单船复制数百份。

## 2026-11-09 状态

四类新船的完整/剖视研究稿及正式网页产物已通过尺寸、构件组、桅位、真实舱口、完整与剖视布局一致、局部通路与绞盘位置的几何检查。坐船和战船曾发现窄甲板被桅座或舱口盖占用，已调整辅桅位置及战船盖板转向；随后发现肋骨穿出船板，四类新船均改为使用内收24厘米的模型肋骨。坐船预览还发现偏置桅座穿壳，已按整个桅座占地范围重算基础高度、缩小偏置承座并增加横向梁，同时将坐战前部辅桅内移。

五船正式导出、来源指纹、颜色/法线烘焙、解码采样、`npm run check`、`npm run build` 已通过。单船网页按船型惰性加载及已覆盖的源页面切换已复核；最终离线 `dist/fleet.html` 已在本机 HTTP 浏览器中完成五船完整/剖视与三种收帆姿态的验收。此项不代替 `file://` 双击或实体手机测试；详细范围和截图见 [FLEET-VALIDATION.md](FLEET-VALIDATION.md)。
