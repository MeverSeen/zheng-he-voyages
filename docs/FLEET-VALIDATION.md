# 舰队复原验收记录

日期：2026-11-04。范围：C1—C5 船只和舰队主体及对应离线构建。

## 已实现

五类船体、龙骨、甲板、船楼与窗格、栏杆、帆骨、主要索具、艉舵、锚与绞盘；剖视中的隔舱与肋骨；按用途区分的货箱、粮袋、马栏与战船兵器架。全部几何是参数化示意，不宣称工程可建造性或考古精度。

宝船有两套尺度：61.2×13.8米的二千料解释，以及《明史》44丈×18丈按尺长0.311米折算的136.84×55.98米。其余船型的尺度、所有船型的帆装和楼舱布局为明确标注的建模假设。

七次切换，记载数量与统一250艘教学编成分别显示；船型筛选、间距、实例选择进入单船、尺度参照、热点与构件目录、深链接和昼夜模式。舰队使用实例化低细节，单船使用按构件合并的高细节。

## 自动检查

- `npm run check`：五类船、宝船两套尺度、完整及剖视几何均为有限数；船体长宽符合数据；所有主要构件存在。
- 高细节宝船20,409三角面；其余高细节船不超过这一数值，全部低于30,000。
- 七次的记载/假设模式与展示数量一致，筛选数量一致；合并后几何非空。
- 原航海图全部航段检查通过（原脚本的港口与内河豁免条件保持不变）。
- `npm run build` 生成三页离线版、兼容文件名和多文件包；`check-build.mjs` 检查全部内联脚本可解析，无外部脚本/样式依赖。

## 浏览器验证

Codex 内置浏览器，本机；桌面1440×900与手机宽度390×844，昼夜模式均查看。手机宽度实测 scrollWidth=clientWidth=390，无横向页面溢出。修复了窄屏初次加载相机未完整容纳船只的问题。

检查了五种船型切换、宝船两种尺度、剖视、构件说明、七次船队中的已载与未载情况，以及250艘场景。离线内联版经浏览器打开，修复了打包字符串替换造成的脚本损坏；构建检查已覆盖这一问题。

250艘、1440×900、当前本机内置浏览器采样60.0fps，27次绘制调用；这是一次现场采样，不是跨设备性能保证。已实际点击舰队中的马船，成功进入对应单船页。

## 限制与后续

- 浏览器工具仅允许HTTP/HTTPS，拒绝file://协议。因此未实际执行双击离线验收；已通过HTTP打开相同自包含文件，并检查无外部脚本、样式依赖。
- 手机验收为桌面浏览器的窄屏视口，并非实体手机 GPU 与触摸性能认证。
- 马船等四类模型的尺寸仍为假设，不把展示模型视为已经完成历史考证。
- 暂不加入哥伦布旗舰复原；先保留人物与105×68米场地参照，遵循船只主体优先的要求。
- 港口环境及具体人物角色未开展，作为后续范围。
- 世界全图、人物页面和全站E4验收不属于本次完成项。

## 船体深化记录（同日追加）

本轮调整船尾宽度、桅位和主帆高低；独立设置争议大船方案的吃水8米、舷中干舷4米，以现代模型深度解释作组合示意，不把原有61.2米方案的纵深比例直接放大。楼层高2.25米、床桌、外梯等使用独立尺度。数据和页面明确区分尺度证据与帆装假设。

参考核对：[长荣海事博物馆宝船](https://www.evergreenmuseum.org.tw/collection/79)说明其馆藏来自现代推论、采用九桅十二帆；本项目仍为九桅九主帆布局示意，未宣称复制该馆模型。[Royal Museums Greenwich 商船模型](https://www.rmg.co.uk/collections/objects/rmgc-object-6901)仅用作舱口、绞盘、桅座的构件比较，不反推明代原船配置。[Science Museum Group 山东五桅商船](https://collection.sciencemuseumgroup.org.uk/objects/co41902/model-of-a-5-masted-shantung-trading-junk)说明后世中国船桅位与支撑方式多样，不能套用统一的等距桅位和西式侧支索体系。

新增真正的甲板开口、围板、盖板、下舱梯；船楼改为独立楼板和有门窗开口的墙体；内部增设横梁、肋骨、支柱、桅座、纵向龙骨材和架高舱底板。货物始终位于舱内，剖视不再搬动货物。艉桅避开船楼后墙，其帆面避开楼顶。

自动检查覆盖五类船及两套宝船尺度：桅杆不穿船楼与舱口，射线确认舱口实际开孔，剖视前后全部布局参数一致。最高28,317三角面，低于30,000预算；旧版20,409面记录仅适用于前一轮。航段回归通过。港口环境未增加。

本轮浏览器复核：宝船两套尺度剖视、二千料方案俯视及战船390×844窄屏剖视。发现并修复海面穿入打开舱口的问题：单船海面按船壳在海面高度的轮廓挖孔，网格不再穿过舱内。窄屏实测页面宽与内容宽均390；当前预览无控制台错误或警告。本轮未重测250艘帧率，前述性能采样属于上一版。

## 船楼与桅帆深化（2026-11-04）

先推送第一版样板（7bfafc5），再逐项核对小说、现代博物馆复原、清代汇编大福船图说、晚明漕船记载与后世船模。来源与采用范围见 FLEET-PLAN 的形制核对表，网页新增四项来源与精修版专用构件说明。九桅九主帆和三层艉楼未被提升为已证实史实。

Blender 中替换了原有船楼与整套桅帆：船楼设柱梁、围壁、窗洞与局部开启木窗板、露台栏护；底层抬至艉部甲板以上并设支承，登楼梯实际落在主甲板，上层使用带真实屋面开口的陡梯。桅帆设九组独立构件，每帆八幅、九道帆骨/上下帆杆、桅顶滑轮、升帆索及四支汇合控帆索；精确配置与材料仍是示意。修正了帆面与船楼干涉、索具落点和原外梯悬空问题。

- 完整模型29,865三角面，剖视22,183；均小于30,000。
- 导出测试检查实际GLB中的六构件组、九组帆面、米制与轴向、船体尺度、真实门洞、甲板舱口、屋面梯口、帆面顶点不进入船楼，以及完整/剖视布局一致。
- 网页适配器实测每船33个材质批次；检查合并后尺寸、三角面和销毁实例后源模型仍可复用。此项不是跨设备帧率认证。
- `npm run check`（含航线回归）与 `npm run build` 通过。离线单页内嵌两份GLB，约5MiB。
- 实际浏览器检查离线页完整与剖视、船楼与桅帆构件说明、精修/参数模型切换；未见控制台错误或警告。
- 检查总览、船楼和桅帆三幅Blender渲染图。未做真实船舶稳性、风载、索具受力或收帆动力学验证；未新增实体手机、file://双击及250艘帧率测试。
